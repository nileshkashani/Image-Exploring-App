## Overview

Image Exploring App is a modern web application for discovering high-quality images through a fast, responsive, and intuitive interface. It focuses on delivering a smooth browsing experience with dynamic image loading, detailed previews, and real-time interactions while maintaining clean architecture and scalable code.

---

## Features

- Infinite image exploration
- Responsive masonry grid
- Full-screen image preview
- Real-time interactions
- Fast image loading
- Optimized API requests
- Mobile-first responsive design
- Modern UI with smooth animations

## Tech Stack

| Layer | Technologies |

## Installation

```bash
git clone https://github.com/nileshkashani/Image-Exploring-App.git

cd Image-Exploring-App

npm install

npm run dev
```
